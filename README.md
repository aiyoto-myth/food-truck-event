# Booking Check: food truck event calculator

Is this event worth it? Put in the booth fee, the commission and your costs; get your break-even, what you keep on a slow, normal and busy day, the most you should agree to pay, and a counter-offer message for the organizer. Log how each event really went.

Use it: https://aiyoto-myth.github.io/food-truck-event/

Free, no sign-up, nothing uploaded. Everything stays in your browser.
